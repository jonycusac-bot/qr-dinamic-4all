# QR Dinamic 4all

Proyecto independiente para QR dinámicos con nombre y logo personalizables desde **Mi marca**. Conserva la redirección estable, cambio de destino, historial y estadísticas.

- GitHub privado: https://github.com/jonycusac-bot/qr-dinamic-4all
- Web: https://qr-dinamic-4all.vercel.app
- Neon: old-cell-68983129, rama main, Frankfurt.

## Continuar

Ejecutar npm install y npm run dev en esta carpeta. Configuración privada en .env.local; clave del panel en .demo-access.txt. No subir estos archivos.

Comprobaciones: npm run lint, npm test, npm run build y npm run test:neon. Migraciones: npm run db:migrate con conexión directa.

## Alcance

Esta demo tiene un espacio de trabajo y una clave de panel. La marca se comparte en ese espacio. Antes de ofrecer un servicio a múltiples clientes deben implementarse cuentas, aislamiento de datos por cliente, límites y facturación. No incluye pagos ni registro de clientes todavía.

El proyecto Illusion permanece separado en C:/Users/Usuario/Desktop/QR. No copiar sus credenciales ni sus datos.
